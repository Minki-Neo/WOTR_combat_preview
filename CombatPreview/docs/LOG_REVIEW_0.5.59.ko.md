# 0.5.59 대상 제외 및 피해/명중 이상치 진단

2026-11-23. 최신 실행은0.5.57.0, 세션042f8db5d37148e68fda219b5951d32f다. 로그가 진행/회전 중이므로 첫 분석과 후속 분석의 보존 범위가 다르다. 새0.5.59의 실전 화면/수치/FPS는 아직 미검증이다.

## 아군 계산 제외

원인: WouldCurrentlyTarget에서 관측한 후보를 전달 단계 AbilityTargetsAround의 Enemy/Ally 조건과 다시 대조하지 않고 계산 큐에 넣었다. 목록을 비운 뒤 호버 대체 대상이 아군을 다시 넣을 수도 있었다. 아군 후보가32명 제한을 차지할 가능성도 있었다.

게임 로컬 Blueprint에서 AngelStormOfJusticeAbility는 AbilityTargetsAround.m_TargetType=Enemy이며 AngelBoltOfJusticeAbility는 적만 지정하는 단일 대상 플래그다. 이름별 예외 대신 공통 관계 필터를 추가했다.

- Enemy 범위기는 caster.IsEnemy, Ally 범위기는 caster.IsAlly로 판독한다. Any 범위기는 아군 피해 가능성을 유지하며 일괄 제거하지 않는다.
- 범위 선택기의 지원된 조건은 읽기 전용 판독 결과가 명확히false일 때만 제외한다. 미확인 조건/복합·파생 선택기는 보수적으로 유지한다.
- 관측 대상 창에 넣기 전과 패널 큐/32명 제한/호버 대체/커서 우선순위 전에 적용한다. 이미 쌓인 제외 대상도 큐 동기화에서 제거된다.
- 범위 선택기가 없는 직접 지정 주문은 적/아군/자기 지정 플래그를 적용한다. 미확인 지점 지정·복합 전달을 그 플래그만으로 제거하지 않는다.
- areaTargetFilter에 후보/유효/제외 수와 누적 excludedObservationSamples를 남긴다. 누적 값은 반복 관측 횟수이며 고유 대상 수가 아니다.

근거: work/area-filter-059.txt의 AbilityTargetsAround.Select IL과 로컬 blueprints.zip. 실제 Select/WouldCurrentlyTarget/조건 evaluator를 실행해 재현하지 않는다.

## 피해 및 명중 검증 보강

사용자 요청에 따라 분석기에 weaponRollDamageReview를 추가했다.

1. 실제 d20 최종 눈과 AB/AC를 자연1/20 기본 규칙으로 대조하고 재굴림 history와 signedRerollCount를 함께 보존한다. 은폐 실패/거울상은 단순 AC 성공과 실제 명중 결과의 차이를 설명하는 별도 단계로 처리한다. 설명 안 되는 결과는 ReviewSpecialRuleOrArithmetic이며 특수 자동 명중 등 확인 전 게임 오류로 단정하지 않는다.
2. 실제 피해는 같은 세션·공격 굴림·대상에 연결된 피해 이벤트를 합친다. 표시된 확률 가중 기대값과 비교하는 대신 **명중 시 평균**을 기준으로2배 초과 또는25% 미만을 우선 검토 후보로 뽑는다. 임계값은 오류 판정/통계적 유의성 기준이 아니다.
3. 후보에 표시 주사위 성분, 실제 diceBase/diceModified/bonus/rollResult/감소량/최종값/정밀피해/난이도 배율을 붙인다. 같은 굴림의 여러 피해 이벤트는 추가 타격·복제 피해·추가 성분 등 문맥을 분석해야 하며 합계 자체가 무조건 같은 예측 행과 비교 가능하다는 뜻은 아니다.
4. 입력 변경/공격 모드 변경과 행 연결 후보 여부를 그대로 유지한다. 조건이 달라진 기록을 정식 수치 검증으로 승격하지 않는다. 후보 목록은24건/굴림 목록16건으로 제한하되 전체 후보 수는 따로 집계한다.
5. 새 미리보기 로그에 meanOnNormalHitAfterDefense와 meanOnCriticalHitAfterDefense를 추가했다. 새 로그에서는 실제 일반/치명타에 맞는 평균을 선택한다. 구버전 치명타는 평균이 없어 제외하고, 일반 피해의 구버전 대체 평균은 치명타 확률을 포함한 조건부 평균임을 명시한다.

## 실제 대조 결과와 추가 분석

첫 보존 범위에서 실제 굴림669건을 확인했으며 d20/AB/AC와 hit의 설명 안 되는 산술 차이는 발견되지 않았다. 이것은 명중 확률 분포 전체의 검증이 아니다. 이후 회전된 범위에서는404건, 산술 검토 후보0건이었다.

후속 피해 분석은 연결된 명중시평균128그룹 중 이상치 후보27그룹이다. 비교 불가 사유는 예측 신원 부재151, 명중굴림 연결 부재19, 구버전 치명타 평균 부재19, 행 부재10이었다. 후보들은 입력 변경/공격 모드/행 후보 제한이 있어 확정 오류가 아니다. 기댓값과 실제값이 다르다는 이유만으로 주사위 모델을 바꾸지 않는다.

초기 보존 범위에서 구체적으로 확인한 사례:

- seq1182/beta-167: 미리보기1d4+8, DR10 적용 후 명중시평균0.75. 실제 diceModified1d4+14, 눈2, 감소0, 피해16. 피해 보너스와 방어 적용 차이가 커서 단순 운으로만 설명할 수 없는 입력 차이 후보다. 상태 변경 기록이 있으므로 누락 효과/관통 근거를 더 추적해야 한다.
- seq1090/beta-159: 미리보기1d10+10에 DR10 적용, 실제1d10+12와 추가2d6, 실제 감소0으로 합계29. 추가 성분·보너스·DR 관통을 분리해 검토해야 한다.
- 같은 공격 굴림에 동일한 피해 성분이 여러 이벤트로 기록된 사례도 있다. 다중 발사/부가 공격 등의 가능성을 확인해야 하며 이를 임의로 중복 로그로 삭제하거나 무조건 한 발 피해로 비교하지 않는다.

## 남은 개선사항

- 위 보너스/추가 피해/DR 관통 차이의 활성 출처 및 전체 공격/다중 발사 상태를 정확히 예측에 반영하기.
- 동일 조건 대조 표본과 반복 확률 검증 확보. 한 번의 d20/피해값은 확률 정확성을 증명하지 않는다.
- 축복의 복합 소모, 전체 주변 전파, 치유/특수 문맥/장판, 보호막 근사 오차와 단일 대상 지연.
- 새 대상 필터 로그와 실제 아군 행 제거/적 대상 수·성능 확인.

검증: C#25,639개 단언+27-action 회귀, 게임 메타데이터224개, Python19개. 아군 피해 범위/아군 치유 유지, 적전용 아군 제거, 호버·우선순위 재유입 방지, 40아군 후보 뒤 적이 제한에 밀려나지 않는 경우를 검사했다. 피해 분석은 확률가중 기대값과 조건부 평균의 구별, 이벤트 합산, 치명타 평균, 실제 재굴림 기록과 은폐 단계 구분을 검사했다. 새 DLL의 게임 통합 검증은 별도이며 게임 파일은 교체하지 않았다.
