# 주문 공통 판독과 정의의 번개 누락 분석 — 0.5.39

## 확인한 근거

- 설치된 Info.json과 최근 진단 로그의 실행 버전은 0.5.36입니다. 0.5.39는 별도 설치 파일로 제공합니다.
- 제공 게임은 2.7.0x, Assembly-CSharp MVID는 `90a9869c-2792-4c7b-bfb7-5a8b33da7c82`입니다.
- 정의의 번개 Blueprint는 `c82168800b665324f8b4807b531fea46`입니다. 직접 피해 액션, CL 랭크, 대상 조건 분기, 1.5초 전달 지연을 사용합니다. 공격 명중 굴림과 SR은 없습니다.
- 대상 특성·성향·직업에 따라 CL개 D12/D10/D10/D8/D6 신성 피해 중 하나를 선택합니다. 피해 액션 자체는 내성 반감이 없습니다. 네 가지 분기의 반사 내성은 뒤의 상태 효과를 판정합니다.
- 실제 로그에 다섯 피해식이 전부 조건 후보로 나열되고 `내성 효과 탐색 한도 초과` 및 `ConditionalOrCustomDC`가 기록되어 있습니다. 0.5.36에는 CL 관측이 비어 있는 기록도 있습니다.
- UMM 로그에는 HCO가 이 주문의 반사 실패 5%를 표시한 기록이 있습니다. 이를 피해가 들어갈 명중률 5%로 해석하면 안 됩니다.

## 공통 결함과 수정

1. 직접 내성 탐색의 깊이 제한이 4였고, 장판·버프 연결 탐색과 같은 예산을 사용했습니다. 선택되지 않는 깊은 분기나 후속 버프 탐색 때문에 직접 내성까지 전부 미확인으로 바뀌었습니다. 직접 액션 탐색은 깊이 12·512노드로 제한하고, 연결 효과의 탐색 예산을 분리했습니다. 실제 주문의 27개 액션 구조로 기존 제한의 실패와 새 탐색의 완료를 회귀 검사합니다.
2. 조건부 액션을 피해 후보 목록으로만 읽었습니다. 이제 대상/시전자 특성, 버프, 성향, 직업 조건을 해석하여 실행 경로를 고르고 내성별 최종 분기를 구성합니다. 주문 이름이나 정의의 번개 GUID를 검사하는 실행 코드는 없습니다.
3. `AbilityDeliverDelay`를 미지원 전달 방식으로 취급했습니다. 지연만 있고 명중 굴림을 요구하지 않는 전달은 지원하며, 명중 판정 없음과 상태 효과의 내성을 구분합니다.
4. 주문 선택·대상을 별도 선택 관리자와 `MouseHighlighted`에만 의존했습니다. 게임의 현재 턴 `CurrentAbility`와 `m_HighlightedUnit`을 우선 읽습니다. HCO 객체나 계산 결과를 읽어오는 경로가 아닙니다. 이전 로그에는 패널이 숨겨진 정확한 프레임의 상태가 없으므로, UI 누락의 특정 순간은 소급 확정할 수 없습니다.
5. 파라미터가 아직 관측되지 않으면 CL 피해식도 모두 비었습니다. 주문책의 기존 상태에서 기본 CL을 별도로 판독하고, 주문별 추가 CL 보정은 별도라는 출처를 기록합니다. 최종 DC·CL 관측이 있으면 기존 상태 일치 검사를 통과한 값을 우선합니다.
6. 뒤의 상태이상 내성이 미확인이면 앞에서 이미 결정된 피해도 숨겨졌습니다. 미확인 확률을 추정해 넣지 않고, 그 내성의 성공/실패 어느 쪽에서도 피해가 같으면 공통 피해 기댓값을 유지합니다.
7. 대상·시전자 판독이 실패하면 패널 자체를 숨겼습니다. 이제 주문 제목과 대기 사유를 표시하고, 예외가 생긴 주문은 대기 화면과 재시도 간격을 사용합니다. 주문 한 건의 판독 오류로 전체 미리보기 설정을 끄지 않습니다.

## 현재 한계

- 정의의 번개의 강한 약화 버프처럼 **피해 후 버프가 붙고 다음 내성이 달라지는 경우**가 있습니다. 새 버프의 최종 부여 여부와 상태 변화를 아직 완전히 시뮬레이션하지 않으므로, 앞서 상태 효과가 있으면 뒤 내성의 분기 확률은 미확인으로 남깁니다. 피해가 그 내성과 독립이면 피해 기댓값은 유지합니다.
- 상태이상은 최종 버프 면역을 모두 재현한 적용 확률이 아니라 부여 시도로 표시합니다. 복잡한 재시전·대상 전환·회복·공유 값 덮어쓰기 액션은 공통 분석의 미지원 노드로 기록합니다.
- 기본 CL 판독은 아이템·특수 파라미터 계산기·합성 주문의 모든 보정을 대체하지 않습니다.
- 실제 게임에서 0.5.39 UI·결과·첫 조준 FPS를 확인하는 단계는 남아 있습니다.

## 추가 공통 계산

- 여러 직접 피해 성분의 공유 굴림·공통 내성과 발사체별 판정, 거울상, 임시 HP를 함께 계산하는 유한 분포 엔진을 추가했습니다. 계산량 한도를 넘으면 근사/미확인 출처를 유지합니다.
- 무기 종류나 공격자가 달라져도 표시된 순서에 따라 거울상과 지원되는 물리 보호막을 이어 계산합니다. 실제 게임의 공격 스케줄 순서를 인증한 값은 아닙니다.
- 읽은 주사위 분포를 재사용하고, HUD 바인딩 관측으로 초상화 경계 후보를 등록합니다. 이미 바인딩된 HUD에서 모드를 켠 경우에는 기존 탐색을 예비 경로로 사용합니다.
- 판독 불가 상태는 `branchAnalysis.status`, `unsupportedNodes`, `unknownSaveStages`에 기록합니다. UMM에는 `Spell panel:` 선택 경로와 대기/표시 상태가 남습니다.
