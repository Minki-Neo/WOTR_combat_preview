## 0.5.58 수정

1. **직접 판정 표의 전부 누락**: seq275 끔찍한 웃음은 DC31/CL13을 읽고도 ContextActionOnRandomTargetsAround 때문에 분기 해석을 통째로 중단했다. 로컬 Blueprint는 주 대상에게 웃음 버프를 먼저 시도하고 전염 특기가 있으면 주변 무작위 대상에게 같은 주문을 전파한다. 새 공통 경로는 이미 계산한 직접 분기와 효과 시도를 남긴다. 주변 효과는 실행/추첨하지 않는다.
2. **범위 표시와 불확실성**: secondaryTargetEffects.status=Unmodeled, branchAnalysis.status=PartialSecondaryTargetEffects를 기록한다. 표 제목은 ‘주 대상 직접 판정’, 안내는 ‘주변 전파 확률·추가 효과·HP 영향 미계산’이다. 주변 효과가 이후 주 대상/시전자 상태를 바꿀 가능성이 있으므로 관련 상태를 미확인으로 전환하고 해당 분기의 전체 피해/HP 기대값을 null로 둔다. 이를0피해나 직접 피해만의 전체 기대값으로 대체하지 않는다. 대상수0/빈 액션/확정 도달확률0인 분기는 무작위효과로 오인하지 않는다.
3. **반복 판독 부하**: 0.5.55의 SchoolInputs는 ScopedReadMemo를 사용했지만 주문 배치에 해당 Begin 스코프가 빠져 있어 실제 재사용이 비활성화돼 있었다. SchoolInputs 스코프를 추가해 동일 동기 배치의 의존성 키/독립 매개변수 계산에서 같은 학파·특기 스냅샷을 재사용한다. 프레임을 넘겨 캐시하지 않는다. spell-school-inputs 측정 구간을 추가했다. CPU/FPS 개선 수치는 아직 측정하지 않았다.
4. **검증 집계**: 분석기에 parameterComparisonReview를 추가했다. 누락/미지원/불완전 수치와 유효 비교를 구분해 ‘차이0’의 실제 분모를 보고한다. secondaryTargetPreviewSamples도 추가했다. bool/NaN/None을0차이로 처리하지 않는다.

## 남은 개선사항

1. **축복의 복합 소모**: 행운과 결의의 축복은 Morale+4 조건부 보정 외에 SavingThrowBonusAgainstDescriptor와 AddFeatureIfHasFact를 포함한다. 소모될 때 동반 효과가 후속 내성에 주는 변화를 아직 끝까지 계산하지 못한다. 같은Morale 기존+0/+2를 읽는 경로는 이번 로그에서 확인됐지만 결과 전체는 미확인이다.
2. **주변 전파 전체**: FilterNoFact, 반경, 실제 대상 집합, 무작위 선택과 재귀 전파·효과 면역·기존 버프를 포함한 전체 확률은 미구현이다. 새 표는 그 이전 직접 판정만 표시한다.
3. **피해 검증 공백**: 무기 입력 변경/공격 모드/유효기간의 대조 공백을 줄이고, 실제 굴림 뒤 재구성만으로 기대값을 인증하지 않도록 해야 한다.
4. **성능**: 단일 대상16ms초과 표본이 남는다. 새 spell-school-inputs 비용과 전체 프레임 시간을 대조한 뒤 추가 분할/상한을 정해야 한다.
5. **기존 범위**: 치료량/HP증가, 아이템/특수 계산기/장판·연결 효과, 억제/가상 스탯의 유형 보정, 보호막 근사 오차 및 전체 타격 순서.

근거: 실제 최신 JSONL/UMM, 로컬 blueprints.zip의 HideousLaughter 및 HideousLaughterBuff, work/linked-actions-057.txt의 무작위 액션 IL. HCO 값을 계산 입력으로 사용하지 않는다. 새0.5.58의 실전 UI/값/FPS는 미검증이며 게임 파일 교체/재시작은 하지 않았다.
