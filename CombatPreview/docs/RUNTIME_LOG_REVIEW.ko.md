시작 후 약 116.7~237.4초입니다. 공격/피해 구독과 기록은 이 사용자 실행 범위에서 동작한 것으로 확인됩니다.
구독 해제, 예외 주입, 실제 HP/자원/RNG 비간섭, 게임 예측 정확도까지 검증된 것은 아닙니다.

## 진단에서 드러난 문제와 수정

1. 부모 무기 공격 없이 이름 없는 대상을 상대로 AC10인 굴림 15건이 섞였습니다. 기존 로그에는 IsFake가
   없어 이들이 모두 가짜라고 판정할 수 없습니다. 0.2.2는 게임의 IsFake 플래그가 true인 이벤트를
   제외하고, 그 외 부모 없는 굴림은 unassociated-observation으로 분리합니다. 예측 비교에는 사용하지 않습니다.
2. defenseEvidence의 512자 제한 때문에 긴 미지원 안내 뒤의 캐시 상세 7건이 가려졌습니다.
   0.2.2는 defenseMissing/defenseObserved 배열로 분리하고 개별 항목의 길이와 배열 크기를 제한합니다.
3. 양수 m_RemainPool로 HasConsumablePool을 설정하던 코드는 잘못됐습니다. 제공된 게임 DLL의
   AddDamageResistanceBase.ComponentRuntime은 UsePool=false일 때도 이 캐시를 초기화할 수 있습니다.
   0.2.2는 blueprint backing field의 실제 UsePool을 읽습니다. 값 미상은 Unknown, true/잔량0도 Present입니다.
   기존 7건 모두 실제로 보호막이 없었다고 단정할 수는 없습니다. 새 로그에서 UsePool 값을 확인해야 합니다.
4. 0.2.1 로그에는 세션 구분과 게임 버전이 없었습니다. 0.2.2 schema 2는 모든 행에 sessionId,
   recordSequence, runtime 버전/MVID를 넣어 재시작/파일 회전 후에도 출처를 구분합니다.

모든 NoPrediction은 기존 미리보기 차단 정책에서 예상한 결과입니다. rawDamage와 reportedDamage의
차이를 DR 또는 예측 오차로 판정하지 않습니다. 이 필드들은 실제 피해 계산의 서로 다른 단계이며,
수정자/난이도/최소값/리다이렉트/임시 HP의 의미가 다릅니다.

## 다음 확인

0.2.2를 게임 종료 상태에서 설치하고, 같은 방법으로 진단을 켠 뒤 일반 무기 공격이나 풀어택 한 번을
수행해 JSONL을 확인합니다. 새 행의 schema=2, runtime.gameVersion 및 실제 로드된 UMM/Harmony/MVID,
유효한 rollEventId 연결, defenseObserved의 UsePool/캐시 상세가 필요합니다. 현재 로그로 게임 표시 버전을
소급 확정할 수는 없습니다. 새 빌드도 hover 예측은 차단된 상태입니다.

## 0.2.2 두 번째 사용자 로그 확인 — 2026-11-01

제공 파일은 이전 0.2.1의 64행과 정확히 같은 접두부 뒤에 0.2.2의 11행이 추가된 형태였습니다.

새 행은 모두 같은 sessionId와 일관된 runtime 메타데이터를 가지며 순번은 1~11로 연속입니다.
구조화된 defenseMissing/defenseObserved 배열도 정상 기록됐습니다. 그러나 두 피해 이벤트의 대상은
기존 UnitPartDamageReduction이 없었고 defenseObserved는 빈 배열이었습니다. 따라서 UsePool 필드 판독,
실제 DR/저항/면역/풀 캐시가 있는 경로는 이 세션으로 검증할 수 없습니다.

가짜 이벤트가 없다는 기록만으로 필터가 실제로 발동했다고 증명하지 않습니다. 누적 파일에 남아 있는
부모 없는 15행과 잘린 7행은 이전 버전 데이터이며 새 버전의 재발로 판정하지 않습니다.
NoPrediction 9건, conditionsComplete=false는 현재 차단/미확정 정책과 일치합니다.
이번 결과는 0.2.2의 로드·관측·세션/버전 기록에 대한 제한된 사용자 실행 증거이며, 게임 상태/RNG
보존이나 미리보기 수치 정확도 검증은 아닙니다. 원시 로그/개인 캐릭터명/실제 세션 ID는 저장소에 넣지 않았습니다.

분석 도구는 누적 집계와 세션별 집계, latestIdentifiedSession을 함께 출력하도록 개선했습니다.
새 런타임 버그가 관측되지 않아 모드 DLL/버전/설치 ZIP은 변경하지 않았습니다.
