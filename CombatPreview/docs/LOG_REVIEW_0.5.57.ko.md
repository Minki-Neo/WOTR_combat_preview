## 이번 수정

1. **문맥 매개변수 교체**: 일반 주문책 판독 경로에서 지원된 활성 ReplaceAbilityParamsWithContext의 지정 주문 참조와 현재 주문을 대조한다. 해당 Fact의 m_Context에서 m_Params 또는 가장 가까운 ParentContext의 저장값을 읽는다. 문맥 getter/규칙을 실행하거나 값을 쓰지 않는다.
2. **교체와 가산 구분**: 엔진은 문맥 DC/CL을 ReplaceDC/ReplaceCasterLevel로 지정한 다음, 별도 DC/CL 보너스를 합산한다. 독립 계산에서도 문맥값을 기준으로 사용하고 기존 지원 보너스를 합산한다. RankBonus는 현재 CL 보너스 합이며 원본 문맥 RankBonus를 다시 가져와 중복하지 않는다. 여러 교체가 서로 다른 값이면 등록 순서를 추정하지 않고 거부한다.
3. **메타매직/예외**: 문맥 메타매직이 현재 선택에 이미 포함된 경우만 진행한다. 새 메타매직/미초기화값/출처누락/충돌은 ContextParametersMissingConflictingOrNewMetamagic으로 유지한다. 직접 source OverrideParams 반환과 이벤트의 문맥 Replace는 서로 다른 경로다. 아이템/변환/무주문책/특수 계산기를 일괄 지원한 것은 아니다.
4. **캐시**: 활성한 해당 문맥의 DC/CL/주문레벨/메타매직 값을 엄격한 매개변수 의존성 키에 포함한다. 같은 Fact 객체 내부 값이 바뀌어도 이전 결과를 재사용하지 않는다. 부모 탐색은 순환 검사/16단계 제한을 둔다.
5. **아군 조건**: ContextConditionIsAlly를 caster.IsAlly(target)와 Not/AND/OR 조합에 반영했다. 이는 집단 치료의 알려진 조건 분기 판독을 여는 수정이다. 치유량/모든 치료 분기의 HP증가 UI까지 구현했다는 뜻은 아니다.

근거 IL: work/linked-actions-057.txt, work/context-params-057.txt, work/parameter-handlers-055.txt 및 work/parameter-replacement-053.txt. HCO 값은 사용하지 않는다.
