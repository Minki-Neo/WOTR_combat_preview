## 이번 버전 개선

1. **서술자 DC 보정**: 독립 판독 실패 IncreaseSpellDescriptorDC137회. 로컬 게임 IL을 확인해 첫 SpellDescriptorComponent의 AnyFlag 조건과 BonusDC/ModifierDescriptor 합산을 추가했다. 불일치/서술자 없음은 건너뛴다. 일반 주문책 경로에는 Spellbook이 존재하므로 SpellsOnly 조건도 충족한다.
2. **시전 능력치 교체**: ReplaceAbilitiesStat21회. Blueprint 참조 목록을 확인하고 미해당 주문은 판독을 계속한다. 여섯 기본 능력치/BAB 교체를 DC에 반영한다. OverrideCasterModifier/OverrideDC/독립 신화 주문책의 우선순위를 유지한다. 서로 다른 교체가 충돌하면 등록 순서를 추측하지 않는다. 도메인 특수 교체는 별도 이유를 남긴다.
3. **캐시**: BAB를 매개변수 의존성에 추가했다. 지원된 위치 비의존 핸들러는 일반 매개변수 캐시를 이용하며 원소 서술자 교체 part가 있으면 엄격한 경로를 유지한다.
4. **검증 구분**: 분석기 --expected-version 0.5.53 추가. 최신 런타임 버전 일치를 별도로 보고한다. 버전 일치는 기능/수치/FPS 검증이 아니다.

엔진 ReplaceSpellDescriptorIfCan은 FixNullErrors로 실제 part를 수정할 수 있으므로 호출하지 않는다. 원소 서술자 교체가 있는 해당 주문은 ElementalDescriptorReplacement로 남긴다. 메타매직 결합 주문/도메인/아이템/특수 매개변수 전체를 지원한 것은 아니다. 근거: 작업 공간 work/parameter-handlers-053.txt, work/parameter-replacement-053.txt.

## 남은 개선 및 검증 우선순위

1. **새 DLL의 동일 조건 관측**: 0.5.49~53 실전 확인에 필수. 현재 로그로는 적용 성공/실패를 판단할 수 없다. 오래된 관측값을 강제로 사용해 비교 건수를 늘리지 않는다.
2. **첫 계산 비용**: 보존 UMM 전체에서 spell-preview 최대297.605ms, spell-damage-preview172.523ms, AfterAB235.355ms, AfterCount218.483ms. 구버전 중첩 측정이며 모드 독점 CPU 비용으로 단정하지 않는다. 0.5.51 이후에도 한 대상 내부 계산이 느리면 추가 분할/상한이 필요하다. 새로운 spell-target/spell-batch 측정과 실제 프레임 시간을 대조해야 한다.
3. **주문 출처/HP 누락**: 최신 미해결 주문 출처28건, SpecialOrUnresolvedParameterSource6회, HP 누락33건. 원소 교체/도메인/아이템/특수 문맥, 복합 상태·장판 경로 보강이 남아 있다.
4. **보호막 근사 오차**: 여러 소스 등록 순서, 명중과 소모의 상관, 전체 무기 순서, 임시 HP의 실전 비교가 필요하다. ≈ 표시는 유지하며 피해 사망 확률을 확정하지 않는다.
5. **무기 대조 공백**: 최신 성분236개 모두 정적 방어 재현 비교 불가. 공격모드/조건 변경과 관측 부재를 분리해 재관측해야 한다. 실제 굴림 후 재구성 성공만으로 기대값을 인증하지 않는다.
6. **오류/FPS**: 보존 UMM에서 CombatPreview 오류/예외 문구는 발견되지 않았다. 모든 게임 오류가 없다는 의미는 아니다. 프레임 시간과 모드 구간을 구분해 새 버전 성능을 측정해야 한다.

검증 결과는 VALIDATION.md 참고. 게임에 파일을 복사하거나 재시작하지 않았다.
