# Combat Preview 0.5.0 개발 테스트 — 무기·주문 판정 미리보기

턴제 전투에서 적을 가리키면 대상 체력과 공격별 명중률·피해 주사위·명중 시 평균·방어 전/후 기댓값을 표시합니다.
게임이 이미 계산한 최종 보정을 우선 사용하며, 피트 이름별로 수치를 나열하는 방식에 의존하지 않습니다.
전체 전투 규칙을 재현하는 기능은 아니며 추정과 관측 출처를 구분합니다.

## 주문과 범위 주문

주문을 선택하고 대상을 가리키면 접촉 명중률, 인내·반사·의지 내성 실패 확률과
기본 주문 저항 관통률을 구분해 표시합니다. DC는 이미 완료된 게임 계산에서 읽습니다.
최신 결과가 없거나 별도/조건부 DC가 필요한 경우 `—`로 표시합니다.

범위 주문은 게임이 조준 중 이미 판정한 대상들을 적·아군별로 나열합니다(최대32명).
포함 판정을 관측하지 못하면 커서 대상만 표시하며 범위 포함을 보장하지 않습니다.
서로 다른 적의 확률을 하나로 합치지 않습니다. 패널 위에서는 이전 조준 결과를 보관합니다.

`~`는 기본 판정 추정이며 **내성 실패 확률이 곧 디버프 적용 확률은 아닙니다**.
효과 면역·조건부 내성·재굴림·내성 성공 시 잔여 효과는 별도입니다.
SR은 기본 CL 기준으로 주문 관통 피트/조건부 SR은 미반영입니다.
이 빌드에는 이전 캐시·물리/전체 면역 수정도 포함됩니다. 게임 내 실행 검증은 아직 필요합니다.

## 설치와 조작

1. 게임을 종료하고 `CombatPreview-0.5.0-beta-UMM.zip`을 ModFinder/UMM으로 교체 설치합니다.
2. Ctrl+F10 → Combat Preview → 베타 무기·주문 미리보기 켜기. **이미 실행된 계산 결과 읽기**는 기본 ON입니다.
3. 적을 가리키고 **F6 상세 / F7 대상 고정**을 사용합니다. 키는 UMM에서 바꿀 수 있습니다.
4. 좌측 압축 표에 `#3 제미니 · 발굽`처럼 공격자/무기를 행 옆에 표시합니다. 높이는 최대420(배율 적용 전), 넘으면 스크롤합니다.
5. 적에서 패널로 마우스를 옮겨 상세 버튼/스크롤을 사용할 수 있습니다. 월드 클릭은 패널에서 차단합니다.
6. 마우스가 적을 벗어나면 **보관 중**이며 새 예측으로 기록하지 않습니다. 적으로 돌아가면 갱신합니다.
   고정/패널 포커스가 없으면1.2초 후 닫고, 턴·공격자·장면·능력 선택·비활성화·사망 시 보관을 해제합니다.

중앙 배치·제목 드래그·크기·배율·위치 초기화 설정도 유지합니다. 배경/테두리는 자체 제작이며 다른 모드 그림을 배포하지 않습니다.

## 게임 공통 계산 결과 사용

다음 게임 규칙의 완료 결과를 제한된 Harmony postfix로 읽습니다.

- `RuleCalculateAttackBonus`: 특정 대상에 대한 명중 보정 합계와 보정 내역.
- `RuleCalculateAC`: 해당 공격 유형의 대상 AC.
- `RuleCalculateAttackBonusWithoutTarget`: 무기 자체의 공통 명중 계산 결과. 피트/버프/다른 모드가 이 규칙에 반영한 보정을 함께 얻습니다.
- `RuleCalculateWeaponStats`: 주사위·피해 보정·치명 범위/배율·강화 수치.
- `RuleCalculateAttacksCount`: 이미 계산된 공격 수/반복 페널티.

최종 합계를 받아 기존 보너스를 다시 더하지 않습니다. 상세에는 **게임 AB / 추정 AB**, **게임 AC / 추정 AC**를 독립적으로 표시합니다.
대상 없는 무기 계산을 얻었다고 대상의 AC나 상황 보정까지 확인됐다고 표시하지 않습니다.
예: AC17, AB+9이면 d20 **8 이상**, 기본 확률65%입니다. 자연1 실패/자연20 명중을 반영합니다.

추가 규칙·공격·주사위를 직접 실행하지 않습니다. 게임의 계산 함수를 임의로 호출하면 규칙 핸들러가 상태를 바꿀 수 있으므로,
원래 게임/다른 모드가 계산할 때 결과를 복사합니다. 아직 계산되지 않았거나 유효기간이 지난 항목은 추정으로 남습니다.
무기 일반 결과는1.5초 이내이며 공격자·무기·턴·모드·잡기·활성 팩트·토글·랭크·저장된 컨텍스트·능력치가 바뀌면 재사용하지 않습니다.
대상 결과도1.5초 이내의 제한된 쌍/상태 키를 사용하며 일시적 AB/AC 보정 범위 정리를 허용합니다. 모든 조건 일치의 증명은 아닙니다.
기존 가짜 추정 결과 사본(최대2초)도 보조적으로 읽습니다. 실제 전투 통계에는 가짜 이벤트를 합산하지 않습니다.

## 강력한 공격과 예약 효과

강력한 공격처럼 ON이지만 실제 공격 시작 때 버프가 붙는 능력은 평소 게임 계산에 아직 포함되지 않을 수 있습니다.
현재 켜진 토글과 이미 로드된 예약 버프의 정적 연결을 읽어 **공격 시 적용 예정**으로 구분합니다.
활성 버프와 중복 적용하지 않으며, 실제 활성화되면 게임 계산 결과로 대체합니다. 능력을 켜거나 버프를 직접 부여하지 않습니다.

지원한 공통 보정 컴포넌트의 BAB 배율·피트 랭크·명중 페널티·무기 조건·양손/보조손 피해 배율을 계산합니다.
일반 강력한 공격은 BAB4에서 명중−2, 한손 피해+4/양손+6입니다. 신화/상위 배율은 해당 참조 팩트를 확인한 경우 반영합니다.
게임 결과가 없을 때의 제한된 보조 판독에는 무기 강화·무기 중점화·명중 능력치 치환·범위별 명중 보정도 포함됩니다.
예약 버프가 미로드이거나 동적 조건/액션/컨텍스트가 불명확하면 상세에 미확인 이유를 남깁니다.
모든 미래 발동·자원/발동 조건·특수 효과를 지원한다는 뜻은 아닙니다.

## 자동 DR·저항·면역

제공된 기본 게임 DLL의 활성 방어 소스와 이미 등록된 소스를 읽고 다음 범위를 계산합니다.

- 물리 DR의 무기 유형/공격 유형 필터와 재질·피해 형태·마법 강화·성향·근접 무기 관통 조건.
- 조건 사이의 AND/OR, 플래그 내부의 교집합. 강화+3은 냉철/은, +4는 아다만틴, 강화 합계+5는 성향 관통.
- 적용되는 비중첩 DR/같은 에너지 저항 중 최대값. 에너지 면역과 저항/면역 억제 상태.
- 피해 주사위 분포를 계산해 DR/저항을 적용합니다. `max(평균−DR,0)` 근사가 아니며, 치명타 피해에도 DR은 한 번 적용합니다.
- 같은 에너지 유형의 피해 구성은 합쳐 저항을 한 번 적용합니다. 명중/치명 확률까지 가중한 방어 후 기댓값을 표시합니다.

**후**는 지원된 현재 정적 방어 모델, **전**은 방어 전 값입니다. 상세에 DR 후보·관통·적용 최대값·미확인 이유를 표시하고 로그에도 기록합니다.
소모형 보호막/풀·중첩형 DR·경도·취약/DR 감소 효과·에픽/현실성 특수 관통·여러 물리 구성의 개별 관통/순서는 아직 미지원입니다.
판정에 필요한 미확인 조건이 있으면 후 수치는 **—**이며, 한 공격이라도 계산 불가이면 전체 후 합계도 **—**입니다.
모든 공격 시점 효과/난이도/다른 모드 핸들러를 검증한 최종 실제 피해가 아니므로 `fullConditionsVerified=false`를 유지합니다.
명시적으로 확인한 수동 방어 시나리오는 별도 라벨과 별도 로그 필드로 유지하며 자동 방어 결과와 섞지 않습니다.

명중 시 평균은 치명타를 가중하고 빗나감은 제외합니다. 방어 후 계산 가능 시 방어 후 평균, 그 외 방어 전 평균입니다.
첫 무기 피해 구성만 치명 배율을 적용하는 부분 모델이며, 은폐·재굴림·치명 면역 등 확률 수정은 완전하지 않습니다.

## 기수·탈것·추가 공격

기수/탈것과 각 기존 자연 무기 슬롯을 별도 행으로 읽습니다. 자연 무기는 슬롯별 기본1회이며 BAB 반복을 임의로 더하지 않습니다.
힘+4의 양손 장검은1D8+6입니다. 현재 잡기/보조손 점유·한손 강제·주문전투를 고려하고 음수 힘은1.5배하지 않습니다.
선궁의 **질풍격** 등 확인된 활성 추가 공격과 관측된 공격 수를 지원합니다. BAB2 활 풀어택+질풍격은 같은 보정의2행이며 단타는1행입니다.
제조 보조손·이중 무기·비무장·특수 자연 반복 등 전체 공격 목록은 미확인입니다. 표시한 공격들의 합계입니다.
정보 없는 행을 누락해 완전한 합계를 만들지 않습니다. 장착/자연 무기 생성이나 전체 공격 열거 함수를 호출하지 않습니다.

## 로그와 검증

비교 기록은 미리보기 opt-in 뒤 기본 ON, 화면 알림은 기본 OFF입니다. 자동 전송은 없습니다.
`Mods/CombatPreview/CombatPreview.diagnostics.jsonl`과 `.prev`를 함께 확인합니다. 각 파일1MiB, 초당 최대20행입니다.
무작위 피해 한 번을 기댓값과 비교해 오류로 판정하지 않습니다. AB/AC·무기 구성 차이와 실제 피해를 별도로 기록합니다.
필드는 `docs/DIAGNOSTICS.ko.md`, 검증 기록은 `docs/VALIDATION.md`에 있습니다.

기존0.3.2 관측 설치/사용은 사용자 로그에서 확인됐지만 **0.4.0의 새 관측·예약 효과·자동 DR은 게임에서 실행 검증하지 않았습니다.**
제공된2.7.0x MVID만 허용하며 TTT는 차단합니다. 빌드/순수 테스트 통과가 실제 UI·모든 핸들러·상태/RNG 비간섭을 증명하지 않습니다.
기존 DryRun/event replay/억제 패치는 계속 차단합니다. 새 관측은 미리보기와 결과 읽기 ON일 때만 설치하고 OFF 시 제거합니다.

첫 시험은 같은 적 위에서 F6을 열고 강력한 공격 OFF/ON의 AB·피해·출처를 비교한 뒤, DR 적에게 실제 공격해 로그와 함께 확인합니다.
예약 효과가 미로드로 표시되면 그 이유를 로그와 함께 전달하세요. 게임이 해당 데이터를 로드하기 전에는 임의로 로드하지 않습니다.
