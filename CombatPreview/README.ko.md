# Combat Preview 0.3.2 — 기수/탈것과 상세 보기 베타

턴제 전투에서 적을 가리키면 공격자별 부분 모델을 표시합니다. 대상 현재/최대 체력과 임시 HP,
공격별 명중률·피해 주사위·명중 시 평균·방어 전 기댓값을 보여줍니다. 전체 게임 규칙 예측기는 아닙니다.

## 설치와 조작

1. 게임을 종료하고 `CombatPreview-0.3.2-beta-UMM.zip`을 ModFinder/UMM으로 교체 설치합니다.
2. Ctrl+F10 → Combat Preview (Read-only Beta) → 베타 무기 미리보기 켜기.
3. 적을 가리킨 채 **F6**으로 상세를 열고 닫습니다. **F7**은 현재 대상을 고정/해제합니다.
4. 적에서 패널로 마우스를 옮겨도 유지하며 상세 버튼을 누르거나 스크롤할 수 있습니다.
   패널 영역에 투명한 자체 UI 입력 영역을 두어 뒤의 월드 클릭을 막습니다.
5. 마우스가 대상을 벗어나면 표시 시점의 정보를 보관합니다. 보관 중이라고 표시하고,
   보관 화면을 최신 예측으로 다시 기록하지 않습니다. 대상 위로 돌아가면 갱신합니다.
6. 턴/선택 공격자/장면/능력 선택/모드 비활성화/대상 사망에 따라 보관을 해제합니다.
   고정하지 않고 패널에도 마우스가 없으면 1.2초 후 닫습니다.

키 이름은 UMM 설정에서 바꿀 수 있습니다. 기본 F6/F7이며 잘못된 이름은 기본 키로 동작합니다.
중앙 자동 배치·제목 드래그·크기/배율·위치 초기화를 유지합니다. 상세 설명은 기본적으로 접습니다.

## 기수와 탈것

서로 연결된 기존 기승 파트를 읽어 **기수 / 탈것**을 별도 구역에 표시합니다. 각자의 기존 행동 상태와
공격 모드를 읽고, 주무기 및 풀어택에서 이미 존재하는 자연 무기 슬롯(물기·발굽 등)을 읽습니다.
자연 무기에 BAB 반복 공격을 임의로 추가하지 않으며 슬롯마다 기본 1회 모델입니다.
공격할 수 없거나 정보가 없으면 해당 구역에 이유를 표시하고 합계를 미확인으로 남깁니다.
기수/탈것/각 무기의 표시 및 실제 비교 연결도 서로 덮어쓰지 않습니다.

가속·연타·강제 자연무기 반복·제조 무기 보조손·이중 무기·비무장·모든 추가 타격의 순서/횟수는 미확인입니다.
장착/자연 무기를 생성하거나 전체 공격 열거 함수를 호출하지 않습니다. 현재 읽힌 공격의 합계이며
게임이 실행할 전체 공격 목록이라고 보장하지 않습니다.

## 명중 보정과 상세 값

0.3.1 사용자 로그의 표시 80건 모두 기본 능력치 추정이었고, 비교 가능 5건 모두 AB가 실제보다 낮았습니다.
이전 경로는 특기/강화/상황 보정 등을 전부 고려하지 못했습니다. 해당 수치가 정확했다고 주장하지 않습니다.

0.3.2는 게임/다른 모드가 이미 실행한 `RuleCalculateAttackBonus.OnTrigger` 및
`RuleCalculateAC.OnTrigger` 완료 결과를 두 개의 제한된 Harmony postfix로 관측합니다.
추가 공격/주사위/규칙을 실행하지 않고 인수·결과·원래 함수 실행 여부를 바꾸지 않습니다.
AB는 이미 합산된 Result를 읽어 다시 보너스를 더하지 않습니다. 완료된 무기 피해 구성도 복사합니다.

선택 공격자 또는 연결된 탈것, 대상, 무기, 턴, 위치/HP/fact/기본 능력치가 맞는 최근 1.5초 결과만
사용합니다. AB/AC의 일시적인 보정 범위가 정리되어도 결과를 보관하기 위해 추가 AB/AC 수치 자체는
이 제한된 키에 포함하지 않습니다. 따라서 전체 조건 동일이나 현재 모든 효과의 일치를 증명하지는 못합니다.
완료된 가짜 추정 사본을 읽던 이전 경로(최대 2초)도 보조적으로 유지합니다.

관측 결과가 없으면 **기본 능력치 추정 / 최종값 미확인**으로 표시합니다. 모든 명중 보정이 포함됐다고
표시하지 않습니다. 은폐·재굴림·치명 면역 등 확률 수정 역시 아직 완전하게 반영하지 않습니다.
UMM에서 완료된 규칙 관측 ON/OFF와 AB/AC 관측 횟수를 확인할 수 있습니다.

F6 상세에는 각 공격의 다음 값을 보여줍니다.

- 최근 결과가 있으면 관측된 최종 AC / 명중 보정 합계. 없으면 일반 AC / 기본 보정 추정으로 구분.
- `d20 + 보정 ≥ AC` 식과 필요한 눈금. 예: AC17, AB+9 → **8 이상**, 기본 확률65%.
- 자연 1 실패 / 자연 20 명중. 계산상 필요한 눈금이 20을 넘더라도 자연20만 명중합니다.

## 피해 정보와 지원 범위

피해 주사위는 구성별로 줄바꿈합니다. 명중 시 평균은 치명타를 가중하고 빗나감은 제외한 방어 전 평균이며,
기댓값은 빗나감까지 포함합니다. 첫 피해 구성만 기본 치명 배율을 적용하고 추가 구성은 비증폭으로 보는 부분 모델입니다.
**실제 DR·저항·면역·보호막 적용 후 피해는 미확인이라 —로 표시합니다.** 방어 전 값을 따로 보여줍니다.
명시적으로 확인한 수동 방어 시나리오는 별도 라벨과 로그로 계산하며 실제 대상 판독이 아닙니다.

제공된 게임2.7.0x MVID에서만 판독하며 TTT는 현재 차단합니다. 이벤트 재실행/DryRun과 기존 억제 패치는
계속 차단합니다. 새 관측 postfix는 미리보기+기존 결과 읽기가 켜졌을 때만 설치하고 끄면 제거합니다.
직접 만든 어두운 배경·청동색 테두리와 이미 사용하는 GUI 폰트를 사용합니다. 게임/타 모드 그림은 배포하지 않습니다.

## 로그와 검증

비교 기록은 미리보기 opt-in 뒤 기본 ON, 알림은 기본 OFF입니다. 자동 전송은 없습니다.
`Mods/CombatPreview/CombatPreview.diagnostics.jsonl`을 기록하며 현재/이전 파일 각각 1MiB,
초당 최대20행입니다. 실제 무작위 피해 한 번과 기대값을 비교해 오류로 판정하지 않습니다.
상세 필드와 관측 상태는 `docs/DIAGNOSTICS.ko.md`를 보세요.

**새 기승 판독/관측 postfix/입력 유지 경로는 실제 게임에서 아직 실행 검증하지 않았습니다.**
컴파일/순수 테스트는 UI 수명·Harmony 설치·정확도·모든 상태/RNG 비간섭을 증명하지 않습니다.
같은 장면에서 F6 상세와 기수/탈것을 캡처한 뒤 실제 공격하고 JSONL과 함께 확인합니다.
