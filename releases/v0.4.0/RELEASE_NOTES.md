# v0.4.0 — 공통 게임 계산 결과 우선 · 자동 DR

게임의 공통 명중/피해 계산 결과를 먼저 사용합니다. 피트 이름마다 별도 보너스를 추가하는 방식 대신,
이미 실행된 `RuleCalculateAttackBonusWithoutTarget`/`RuleCalculateWeaponStats`의 결과도 읽습니다.
기존 대상 AB/AC/공격 수 관측을 유지하며, AC가 아직 없다는 이유로 관측된 AB까지 버리지 않습니다.
게임 합계를 사용할 때 기존 활성 보정은 중복 가산하지 않습니다. 게임이 아직 계산하지 않은 항목은 추정으로 남습니다.

강력한 공격은 ON이어도 공격 시작 때 버프가 붙을 수 있어 예약 효과를 별도로 판독합니다.
로드된 토글/버프/직접 적용 액션의 지원된 정적 연결과 명중 페널티·피해·BAB/랭크·양손/보조손 배율을 읽습니다.
일반 BAB4 강력한 공격은 명중−2, 한손 피해+4/양손+6입니다. 실제 활성 버프가 있으면 예약 델타를 다시 더하지 않습니다.
토글·랭크·저장된 컨텍스트·능력치·무기/잡기·턴 변경 시 이전 공통 결과를 재사용하지 않습니다.
예약 액션/미로드 참조/미확정 동적 값은 상세에 이유를 표시합니다. 능력이나 버프를 실제 활성화하지 않습니다.

자동 DR 계산을 추가했습니다. 활성/등록 방어 소스를 읽어 물리 DR의 AND/OR 관통 조건·재질/형태/강화/성향/무기종류/근접 조건을
판정하고 적용되는 비중첩 최대값을 선택합니다. 강화+3 냉철/은, +4 아다만틴, 강화 합계+5 성향 관통을 구분합니다.
에너지 저항·면역·억제도 반영하며 주사위 분포와 명중/치명 확률을 사용해 방어 후 기댓값을 계산합니다.
DR은 치명 배율 적용 후 한 번, 같은 에너지 저항은 해당 공격의 유형 합계에 한 번 적용합니다.

F6 상세에 계산 출처·게임/추정 AB/AC·필요 d20·예약 보정·DR/관통 내역과 계산 불가 이유를 표시합니다.
패널은 좌측 압축 표/F7 고정/기수·탈것/질풍격/양손 피해를 유지합니다. JSONL은 실제 사용한 행별 방어 후 계산값과 관측/추정 여부를 기록합니다.

소모형 보호막/풀, 중첩형 DR, 경도, 취약/DR 감소, 미확정 에픽/현실성 관통, 여러 물리 구성의 개별 관통/순서는 아직 미지원입니다.
필요한 판정이 미확정이면 후 수치/전체 후 합계는 —이며, 모든 전투 조건을 검증했다는 의미가 아닙니다.
은폐/재굴림/치명 면역 및 모든 미래 발동/추가 공격/다른 모드 효과는 완전하지 않습니다. fullConditionsVerified=false를 유지합니다.
추가 규칙/공격/주사위 실행과 기존 DryRun/억제 패치는 계속 차단합니다. 수동 시나리오는 별도로 구분합니다.

검증: 제공된 게임 DLL 참조 net472 빌드, C#7309 assertions, 독립 Python509 checks/2 XML,
39 C# 구문 검사, 실행 없이 참조 메타데이터33 checks 통과. 설치 ZIP은 모드/설정/고지/안내서6개만 포함합니다.
게임/Unity/Harmony/UMM DLL과 사용자 원시 로그는 포함하지 않습니다. MIT 고지를 유지합니다.
**새 기능의 실제 게임 실행 검증은 아직 없습니다.** 이전0.3.2 관측 증거를 새 기능의 검증으로 간주하지 않습니다.

DR 적에게 실제 공격한 다음 현재 CombatPreview.diagnostics.jsonl과.prev를 함께 확인하면 됩니다.
