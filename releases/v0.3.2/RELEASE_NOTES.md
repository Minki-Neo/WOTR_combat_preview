# v0.3.2 — 기승 공격과 F6 상세

- 기수/탈것을 별도 구역에 표시하고 이미 존재하는 물기/발굽 등 자연 무기 슬롯을 읽습니다.
  자연 무기는 슬롯별 기본1회이며 BAB 반복을 만들지 않습니다. 각자의 행동 상태/모드와 비교 연결을 유지합니다.
- **F6 상세 / F7 대상 고정**. 패널로 마우스를 옮겨도 유지하고 입력 영역으로 뒤의 월드 클릭을 막습니다.
  대상 밖에서 보는 화면은 표시 시점 정보를 보관하며 최신 예측으로 다시 기록하지 않습니다.
- 상세에 관측 AC / 명중 보정 합계 / 필요한 d20 눈금을 표시합니다. AC17/AB+9면8이상입니다.
  자연1 실패/자연20 명중을 반영하며, 관측값이 없으면 일반 AC/기본 보정 추정으로 구분합니다.
- 0.3.1은 실제 사용자 표시80건 모두 기본 추정이었고 비교 가능5건 모두 AB 차이가 있었습니다.
  새 버전은 이미 실행된 AB/AC OnTrigger 결과를 제한된 postfix로 읽어 직접 실행된 외부 계산도 관측합니다.
  추가 규칙/공격/주사위는 실행하지 않고 기존 함수 인수·결과를 바꾸지 않습니다.
- 완료된 규칙 관측 ON/OFF, AB/AC 횟수, 출처, 자연 무기 여부와 requiredD20를 기록합니다.

최근 결과는 제한된 기본 상태/대상/무기/턴/모드 및1.5초 수명을 확인합니다. 전체 조건 동일의 증거는 아니며
관측이 없으면 기본 추정입니다. 가속/연타/모든 추가 공격·제조 보조손·치명/은폐/조건부 효과 등은 미확정입니다.
**실제 DR·저항·보호막 반영 피해는 여전히 미지원**이며 방어 전 값/명시적 수동 시나리오와 구분합니다.

C# **7143 assertions**, Python509 checks,31 C# syntax files, 실제 게임 DLL 참조 빌드와 ZIP 검사를 통과했습니다.
새 기승 판독·postfix 설치/상호 운용·F6/F7·클릭 차단·전체 상태/RNG 비간섭은 게임에서 미검증입니다.
기존 DryRun/event replay/억제 패치는 계속 차단하고 두 관측 postfix만 opt-in으로 설치/해제합니다.
