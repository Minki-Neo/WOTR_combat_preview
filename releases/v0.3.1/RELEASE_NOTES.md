# v0.3.1 — 행동 막대 위 전투 패널

패널을 행동/스킬 막대 위 중앙에 배치하고 공격별 정보를 간략한 표로 정리했습니다.

- 대상 현재/최대 체력·임시 HP를 유지하고, 기본 공격마다 명중률 / 줄바꿈 피해 주사위 / 명중 시 평균 / 기댓값 표시.
- 기본 풀어택의 행별 값과 합계. 평균은 치명타 포함·빗나감 제외, 기댓값은 빗나감 포함입니다.
- 직접 만든 어두운 배경·청동색 테두리·금색 강조, 기존 GUI 폰트 사용. 긴 설명은 상세로 접습니다.
- 실제 행동 막대 화면 경계에 붙이며 판독 실패 시 화면 상대 위치로 배치. 제목 드래그/위치 초기화/기존 설정 이관.
- 이미 생성된 완료된 추정 이벤트에서 최근 AB/AC/복수 피해 구성을 읽을 수 있습니다. 이 모드가 추정을 실행하지 않습니다.
  같은 알려진 상태·대상·무기·턴·모드, 2초 이내에서만 사용하고 없으면 기본 능력치 모델로 돌아갑니다.
- 모든 피해 구성과 명중 시 평균을 로그에 남기고, 추가 구성의 종류/주사위/보너스 차이도 비교합니다.

**범위:** 실제 DR/저항/면역/보호막 반영 기댓값은 아직 미확인이므로 —로 표시하고 방어 전 기댓값을 따로 보여줍니다.
명시적 수동 방어 시나리오는 별도 라벨/로그로 계산합니다. 기본 BAB 반복 모델이며 가속·연타·보조손·자연/탈것
추가 공격과 모든 치명/조건부 효과를 계산하는 전체 풀어택 예측은 아닙니다. 기존 추정이 관측되지 않으면
복수 피해 구성이나 상황별 명중 보정도 얻지 못할 수 있습니다.

0.3.0 사용자 증거에서 패널/체력 표시와 비교 연결은 확인됐지만 비교 가능 4건 모두 AB 차이가 있었습니다.
새 경로가 이를 해결했다고 실제 게임 검증 전에는 주장하지 않습니다. C# 7,118 assertions, Python509 checks,
29 C# syntax checks, 실제 게임 DLL 참조 빌드 및 ZIP 검사를 통과했습니다. 새 UI/추정 사본/전체 상태·RNG 보존은
게임에서 검증이 필요합니다. 게임 자원이나 다른 모드의 그림/DLL은 배포하지 않습니다. MIT 고지를 유지합니다.

설치: 게임 종료 → ModFinder/UMM에서 beta-UMM.zip 설치 → Ctrl+F10에서 미리보기 켜기.
같은 장면에서 패널 위치·줄바꿈·각 공격/합계를 확인하고 스크린샷과 diagnostics.jsonl을 전달하세요.
GitHub 파일 페이지의 Download raw file로 ZIP을 받습니다. 소스 ZIP은 설치용이 아닙니다.
GitHub Release 생성과 ModFinder 중앙 등록은 이 Git 파일 게시와 별개입니다.
