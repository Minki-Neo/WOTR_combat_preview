# v0.5.0 — 주문·범위 판정 미리보기 베타

주문 선택 중 접촉 명중, 대상 인내·반사·의지 내성 실패, 기본 주문 저항 관통률을 구분해 표시합니다.
DC/시전자 레벨은 게임이 이미 계산한 결과를 관측합니다. 최신 결과가 없거나 별도/조건부 DC가
필요하면 계산 불가로 표시합니다. 기본 능력치 판정 추정이며 조건부 보너스/면역/재굴림 등은
완전하지 않습니다. 내성 실패는 디버프 최종 적용률이 아니며 복합 확률을 곱해 표시하지 않습니다.

범위 주문은 게임이 조준 중 이미 판정한 대상 목록을 적·아군별로 표시합니다(최대32명).
주문/조준 위치 변경 및 오래된 포함 판정은 무효화합니다. 범위 자료가 없으면 커서 대상만
보여주고 포함 여부 미확인이라고 표시합니다. 패널 위에서는 이전 조준 결과를 보관합니다.

이전 로컬 수정도 포함합니다: 새 무기 통계가 기존 AB 캐시에 가려지던 문제, 캐시/비교 제외
원인 기록, 피해 형태별 물리 면역과 전체 피해 면역 판독 누락 수정.
게임 규칙/공격/주사위를 추가 실행하지 않으며 기존 DryRun 경로는 차단된 상태입니다.

검증: C#7428 assertions, Python509 checks, C#43파일 구문 검사, 실제 제공 참조 net472 빌드,
게임 코드 실행 없는 메타데이터41 checks, 설치 ZIP6개 허용 목록·CRC·현재 DLL/버전 확인.
게임 UI/실제 주문 및 디버프 적용 정확도는 아직 검증되지 않았습니다. 조건부 SR/효과 면역,
특수 투사체/능력치 대체, 반복 내성/장판/연쇄/합성 주문 전체 결과는 미지원 또는 미확인입니다.

게임 종료 후 CombatPreview-0.5.0-beta-UMM.zip으로 교체 설치합니다.
Ctrl+F10 → Combat Preview → 베타 무기·주문 미리보기 및 이미 실행된 계산 결과 읽기를 켭니다.
게임/Unity/Harmony/UMM 참조 DLL이나 사용자 원시 로그는 배포하지 않습니다.
