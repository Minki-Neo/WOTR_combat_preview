# v0.3.3 — 양손 피해·질풍격·좌측 압축 표

- 장검의 기본 무기 분류만 보던 오류를 고쳐 실제 잡기/일반 자동 잡기를 반영합니다.
  양수 힘+4를 양손으로 쓰면+6, 한손이면+4이며 음수 페널티는1.5배하지 않습니다.
- 선궁의 질풍격 등 지원한 활성 추가 공격 효과를 읽습니다. BAB2 활 전력 공격은 두 같은 보정 행,
  단타는 한 행입니다. 이미 계산된 공격 수를 관측하면 해당 패턴을 우선하며 효과를 중복 가산하지 않습니다.
- 공격 수 규칙에 세 번째 읽기 전용 postfix를 추가하고 효과명/횟수 출처/잡기를 로그에 남깁니다.
  직접 규칙/공격/주사위를 실행하거나 전체 공격 열거를 호출하지 않습니다.
- 기본 위치를 좌측으로 이관하고 공격자/무기를 각 행 옆에 붙입니다. 열 제목을 한 번만 표시하며
  F6 상세도 한 줄로 줄였습니다. 최대 높이420(배율 전)이며 초과 내용만 스크롤합니다. F6/F7 유지.
- 방어 캐시 증거에 에너지 종류 및 물리 DR 관통 조건 필드를 추가합니다. 실제 관통/후처리 판정은 아닙니다.

사용자는 랜의 기본 선궁 유지를 확인했습니다. 같은 AB의 두 공격은 질풍격이며 BAB6의 -5 반복이 아닙니다.
제공된.prev에는 물리 DR2/5, 에너지 저항5/10, 전기 면역 등록의 이전 기록이 있습니다. 최신0.3.2 구간은
미리보기97행뿐이라 최신 실제 공격/DR 비교에는 현재 JSONL도 필요합니다. 관측 postfix 설치와10개 모델에서
기존 AB/AC 결과 사용은 확인됐지만 새0.3.3의 실제 잡기/활성 효과/압축 UI는 아직 게임에서 미검증입니다.

검증: C# **7163 assertions**, Python509 checks/2 XML projects,33 C# syntax files, 실제 게임 DLL 참조 빌드.
실제 DR·저항·보호막 반영 기댓값, 모든 조건부 추가 공격/제조 보조손/자연 반복/치명/확률 수정은 여전히
완전하지 않으며 전체 상태/RNG 비간섭을 증명하지 않습니다. 방어 후/전 값을 구분하고 미확인은 —로 표시합니다.
게임/Unity/Harmony/UMM DLL과 사용자 원시 로그는 포함하지 않습니다. MIT 고지를 유지합니다.
