# v0.2.2 — 사용자 로그에 따른 진단 수정

사용자 제공 0.2.1 로그에서 모드 로드와 공격/피해 이벤트 연결이 확인됐습니다. 50개 굴림 중 부모 무기 공격에 연결된 굴림 35건, 명중/피해 14쌍, 풀어택 굴림 22행, 확정 치명타 1건입니다. 원시 로그와 캐릭터명은 게시하지 않습니다.

- 가짜 굴림/피해 제외, 부모 무기 공격이 없는 굴림은 별도 분류하며 비교에서 제외.
- 풀 캐시 양수만으로 보호막이라고 판정하던 오류 수정. 실제 UsePool 필드 사용.
- 방어 누락 이유와 캐시 상세를 별도 배열에 기록해 긴 안내로 수치가 가려지는 문제 수정.
- JSONL schema 2: 매 줄에 세션 ID/순번과 게임·UMM·Harmony·모드 버전/MVID 기록.
- 익명 진단 집계 도구 추가.

C# 6,837 assertions, 독립 검사 509개, 구문 검사 25개 파일 통과. 실제 제공된 게임 DLL로 전체 net472 빌드 성공. 0.2.2의 실제 게임 재실행은 아직 미검증입니다.

**진단용 버전이며 hover 미리보기는 계속 차단되어 있습니다.** 상태/RNG 비간섭과 실제 예측 정확도 검증은 완료되지 않았습니다.

게임을 완전히 종료하고 새 진단용 UMM ZIP을 설치한 뒤 진단을 켜고 일반 공격 또는 풀어택 한 번을 수행해 JSONL을 확인합니다. 게임 참조 DLL은 포함하지 않습니다. ModFinder 중앙 매니페스트 등록과 GitHub Release 생성은 별도입니다.
