# v0.3.0 — 기본 주무기 미리보기 베타

턴제 전투에서 적을 가리키면 기본 무기 모델과 대상 현재/최대 체력(임시 HP 별도)을 표시합니다.
일반 적으로 UI와 기본 계산 검증을 시작할 수 있어 DR 적을 만나기까지 기다릴 필요가 없습니다.

- 기본 BAB 반복 공격, 저장된 AB/일반 AC 기반 확률과 방어 전 기본 물리 피해. 전체 풀어택 예측이 아닙니다.
- 실제 표시 모델과 실제 공격의 AB/AC/무기 주사위·고정 보너스·구성 수 차이를 로컬 JSONL에 연결합니다.
  입력/무기/턴/공격 모드 변경·시간 초과·모델 밖 타격은 건너뛴 이유를 기록합니다.
- 선택 화면 알림은 기본 OFF. 미반영 효과에 따른 부분 모델 차이일 수 있으며 확정 버그가 아닙니다.
- 실제 무작위 피해 한 번을 기대값과 비교하지 않습니다. 방어 관련 파트와 실제 피해/캐시 증거를 수집합니다.
- 기존 이벤트 재실행은 차단하고 별도 읽기 전용 필드 모델만 사용합니다. 미리보기 기본 OFF입니다.
